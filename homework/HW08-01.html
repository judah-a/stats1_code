In an additive model, the prediction lines for different values of the other variable are always parallel. Explain in 2–3 sentences what the parallelism means substantively. What assumption is the additive model making about how hs_grad and inc1000 jointly affect life expectancy?

The prediction lines are parallel in the additive model because the contribution of each predictor to the best predicted values does not depend on the values of the other predictors. Therefore, regardless of the level of income, for example, the level of high school graduation rate won’t change. In other words, the slopes in each case for each predictor are independent of each other, so any values will not change the slope of the other variable, meaning the slopes will stay the same and thus be parallel.

A negative interaction coefficient means that the simple slope for graduation decreases by 0.096 as income increases by 1000 dollars, and the simple slope for income decreases by 0.096 as graduation increases by one percentage point. They are different because the sum of squared errors which is the deviance function in R, measures the sum total of each residual squared, while deviance measures the sum of log-likelihoods (how likely each data point is in the model) times -2. Therefore, deviance is not the sum of squared errors, but rather measures how far away each data point is from the model based on likelihood.

The companion explains that the AIC penalty of \(2k\) corresponds to the expected increase in out-of-sample deviance per extra parameter. In your own words, what problem is the penalty term meant to solve? Why can’t we just pick the model with the lowest deviance (i.e., the best in-sample fit)?

The penalty term is meant to solve the problem of overfitting. If there are too many parameters, the model will overfit to the data it is trained on, meaning that if the same model were to be tested on a new set of data, it might do a bad job of predicting the new model if it corresponds to precisely to the training data. Therefore, excess parameters have a penalty cost to make sure that the likelihood of the model only does better over and above the number of parameters that it has.

The BIC penalty is \(k \log n\) instead of \(2k\). For \(n = 50\), compute \(\log(50)\) and compare it to 2. What does this tell you about how the two criteria will differ in their preferences when \(n\) is small vs. large?

log(50)
[1] 3.912023

log(50) ~ 3.9 which is greater than 2, which means that as n increases, the penalty term will increase. therefore, when n is small, each parameter increase will have less of an effect on deviance versus when n is large, each parameter will need to increase deviance by a greater factor to be preferred to the previous model with less parameters.
